# Reporte de pagos

## Cómo reportar un pago
1. Ve a "Mis facturas" o usa este chatbot.
2. Indica la factura que pagaste.
3. Proporciona monto, moneda, método de pago, referencia y fecha.
4. Confirma la información.
5. El equipo de administración revisará y aprobará el pago.

## Estados de un pago reportado
- **Reportado**: acabas de enviar el comprobante, aún no se revisa.
- **Aprobado**: el pago fue verificado y aplicado a tu saldo.
- **Rechazado**: el pago no pudo verificarse; contacta administración.

## Comprobantes
- Puedes adjuntar una imagen o PDF del comprobante desde el formulario web.
- Conserva el comprobante original hasta que el pago sea aprobado.

## Abonos parciales
- Están permitidos si la administración lo configura.
- El saldo pendiente se actualiza con cada abono aprobado.
